# 书童 · Memorant 市场价值设计

日期：2026-07-24  
状态：已校准（头脑风暴确认）  
范围：面向用户/市场的价值主张与差异化（品类 B），不含实现细节  
关联北星：`docs/specs/2026-07-24-product-doctrine.md`

---

## 1. 定位与主叙事

**品类：** AI 工作助手（经验循环）— 给任何用 AI 干活的人  

**不是：** 笔记软件 / 聊天黑盒 Memory / PKM 方法论课  

**主叙事（闭环型）：**  
干活时主动留下经验 → 再遇相似场景主动用上 → 过时了跟着新做法升级。

**首屏短句（hook）：**  
> 不用你记，也能在下次相似场景用上——并且会越用越新。

**完整一句（对外说明）：**  
> 书童 · Memorant 在你用 AI 工作时主动接住可复用经验；相似场景再现时（哪怕隔了很久）主动找出可参考或可应用的内容；并随新做法自我升级——本地可控，不是又一个要你整理的库。

**价值三角（用户可感知）：**

| 痛点 | 对应承诺 |
|---|---|
| 记录负担 | 不用你专门整理才有资产 |
| 记忆模糊 | 隔月也能找回来 |
| 重复劳动 | 相似场景少做第二遍 |

**匹配主轴：** 相似场景（问题形态、约束、决策类型、语境）。项目/仓只是提高精度的信号，不是产品目的。

## 2. 差异化与划界

### 2.1 对照表

| | 笔记软件 | 聊天 Memory | PKM/第二大脑 | 书童 · Memorant |
|---|---|---|---|---|
| 谁来记 | 你整理 | 模型偷偷记 | 你学方法再记 | 干活时主动接住 |
| 资产在哪 | 笔记库 | 黑盒/厂商侧 | 笔记库 | 本地 Markdown，可审计 |
| 何时出现 | 你去搜 | 偶发注入 | 你去翻 | 相似场景主动递上 |
| 会否过期 | 靠你改 | 不透明 | 靠你改 | 纠正 / 替代 / 强化 |
| 成功标准 | 库很全 | 聊得顺 | 体系很美 | 少重复、找得回、跟得上 |

### 2.2 三句划界（固定话术）

1. **不是笔记软件** — 不靠你养成整理习惯才有价值。  
2. **不是黑盒记忆** — 经验你看得到、改得了、导出得走。  
3. **不是 PKM 课** — 不教你怎么建第二大脑，默认替你跑完「留下 → 用上 → 升级」。

### 2.3 绝不主打的说法

- 「更好的 Obsidian 插件 / 知识库」  
- 单独「给 Claude 加长期记忆」（缺闭环与可控）  
- 「帮你写 PRD/写代码的 Agent」（宿主能力，非本产品价值）  
- 「团队协作 Wiki / 权限系统」（首期非目标）

## 3. 证明点、楔子与成功指标

### 3.1 承诺 vs 举证

| 承诺 | 今天能撑住的 | 必须补齐才敢大声说 |
|---|---|---|
| 不用你记 | Journal 自动采集 | 主动 Distill（不等「请提炼」） |
| 隔久找得回 | 本地 Markdown 长期存 | 场景召回质量 + Project Identity |
| 少做第二遍 | recall 骨架 + legacy 混召 | 相似场景命中；可应用而不只是搜到 |
| 会越用越新 | B→A / 纠正 / 替代机制 | 真实会话里主动跑进化 |

### 3.2 楔子策略

- **对外品类：** 任何用 AI 干活的人  
- **落地楔子：** 先做深 Claude Code 开发工作流（痕迹最好接）  
- **话术：** 闭环讲全品类；开发故事当第一案，再扩 PRD/方案等 Observer  

避免：对外只说「开发插件」把品类做小；也避免主动闭环未达标就宣传「完全不用你管」。

### 3.3 对外成功指标

1. **零吩咐沉淀率** — 有实质产出的会话中，未口述「请提炼」仍产生 memory 的比例  
2. **再遇命中** — 相似场景再现时，召回被采用或引用的比例  
3. **抗遗忘抽样** — 「想不起来了」的主题仍能表面相关经验  
4. **进化发生** — 同主题 promote / supersede / corrected 的发生  
5. **打扰上限** — 非冲突打断次数极低  

**信任附属句：** 本地 Markdown、可导出、可纠正；召回带信任标记（待验证 / 已验证）。

## 4. 与内部北星的对齐

| 市场说法 | 内部原则 |
|---|---|
| 不用你记 | 主动（Proactive First） |
| 相似场景用上 | 场景复用 + 抗遗忘 |
| 越用越新 | 经验迭代（B→A / 纠正 / 替代） |
| 本地可控 | Markdown 事实源；非黑盒 |
| 开发楔子 → 全工作 | 换 Observer，不换经验循环 |

内部排期仍以 `docs/backlog/2026-07-24-memorant-acceptance-followups.md` 的 P0（主动 Distill、Distill 契约、Project Identity）为先——没有这些，市场承诺会空心。

---

## 5. 非目标（价值叙事也不承诺）

- 后台常驻模型、向量库、Web Dashboard、云同步、团队权限（首期）  
- 替代用户做最终判断  
- 强制用户维护命名规范或 PKM 体系
